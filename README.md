## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/pranjalnavgale/latest-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd latest-portfolio
   ```

3. Open `index.html` in your browser to view the portfolio.

For the optional build workflow, refer to the scripts defined in `package.json`.

## 🌍 Deployment

This project is configured for deployment on [Vercel](https://vercel.com/).

1. Import the GitHub repository into Vercel.
2. Review the build configuration.
3. Deploy the project.
4. Add the live portfolio URL here after deployment.
